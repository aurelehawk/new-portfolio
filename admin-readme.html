Vue d'ensemble

Cette interface permet de modifier toutes les parties du portfolio sans toucher au code. Elle gère le contenu, les images et les paramètres SEO avec une expérience moderne et fluide.

Accès & Authentification

URL d'accès

http://localhost:8080/admin.html

Identifiants

  • Nom d'utilisateur : admin
  • Mot de passe : admin123

✔ Stockage local — démo

Fonctionnalités principales

1. Gestion du profil
  • Modification du nom et du titre
  • Description personnelle (courte et longue)
  • Upload de photo et CV (PDF)
  • Liens sociaux (LinkedIn, GitHub, Twitter)
2. Expériences professionnelles
  • Ajout / suppression d'expériences
  • Détails : titre, entreprise, dates, lieu
  • Descriptions : contexte, missions, projets, résultats
  • Technologies utilisées
3. Formation & Éducation
  • Ajout / suppression de formations
  • Diplômes, établissements, périodes et descriptions
4. Certifications
  • Ajout / suppression de certifications
  • Liens vers certificats, dates, ID
5. Compétences techniques
  • Organisation par catégories
  • Niveaux de maîtrise en %
  • Ajout / suppression de compétences
6. Projets
  • Gestion complète avec images
  • Liens GitHub et démos
  • Technologies utilisées
7. Contact
  • Email, téléphone, adresse
  • Liens sociaux
  • Mise à jour automatique
8. SEO
  • Titre, meta-description, mots-clés
  • Open Graph & Twitter Cards

Fonctionnalités avancées

  • Prévisualisation en temps réel et responsive
  • Upload sécurisé avec validation de taille/format
  • Sauvegarde auto dans localStorage, export/import JSON
  • Restauration et nettoyage des données anciennes

Utilisation étape par étape

1. Première connexion
  1. Ouvrir http://localhost:8080/admin.html
  2. Entrer les identifiants
  3. Cliquer sur « Se connecter »
2. Navigation

Utiliser le menu latéral pour accéder aux sections du portfolio.

3. Modification du contenu
  1. Sélectionner une section
  2. Modifier les champs
  3. Utiliser Ajout/Suppression pour les listes
  4. Cliquer sur « Sauvegarder »
4. Upload de fichiers
  1. Cliquez sur « Upload »
  2. Sélectionner le fichier
  3. Attendre la confirmation
  4. Le fichier est intégré automatiquement
5. Prévisualisation
  1. Cliquer sur « Prévisualiser »
  2. Une nouvelle fenêtre s'ouvre
  3. Vérifier les changements
  4. Fermer la fenêtre
6. Publication
  1. Vérifier la prévisualisation
  2. Cliquer sur « Sauvegarder »
  3. Consulter http://localhost:8080/

Dépannage

Interface ne se charge pas

  • Vérifier le serveur local
  • Actualiser la page
  • Vider le cache navigateur

Modifications invisibles

  • Cliquer sur « Sauvegarder »
  • Actualiser le portfolio
  • Ouvrir la console (F12) pour erreurs JS

Upload — erreurs

  • Taille max 5MB
  • Formats : JPEG, PNG, GIF, WebP
  • Autoriser les popups

Perte de données

  • Stockage dans localStorage
  • Éviter de vider le cache
  • Exporter régulièrement (JSON)

Développement futur

  • Backend réel (base de données)
  • Authentification avancée (rôles & permissions)
  • Upload cloud et stockage serveur
  • Analytics d'utilisation
  • Multi-langues
  • Application mobile

Support
